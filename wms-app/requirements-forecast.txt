# core WMS app (items, stock, receive/pick, IHA report) does not import any
# of this, and should keep running even where this file was never installed.
#
# Install alongside the core requirements:
#   pip install -r requirements.txt -r requirements-forecast.txt
#
# Same pins as iha-saas/requirements.txt, the latest known-working
# generation of this stack -- see that file's comment and
# iha-saas/CLAUDE.md "Deployment & drift" for the Streamlit Cloud build
# incident (pandas 3.0/numba/statsmodels wheel resolution) these pins avoid.
# That incident was specific to Streamlit Cloud's own memory-constrained
# build environment, not the libraries themselves, but the pins still
# matter regardless of host.
#
# ARM (Oracle aarch64 VPS) compatibility: confirmed installing/importing on
# an x86_64/arm64 Mac dev machine only, as of 2026-09-20. NOT yet verified
# on the actual deploy target -- see the smoke-test script this pin change
# was made alongside (scripts/smoke_test_forecast_deps.sh) and
# docs/FORECAST_SPEC.md's open questions.
